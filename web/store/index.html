怎么装

以小米 / HyperOS 为例，其他安卓手机大同小异。需要 Android 8.0 或更高。

  1. 用手机自带的浏览器打开这一页，点「下载 APK」。从微信里打开的话，先点右上角「···」，选「在浏览器中打开」，微信里下不了安装包。
  2. 下载完点开安装包。系统提示「禁止安装未知来源应用」时，按提示允许当前浏览器安装，再回来继续。 设置 → 隐私保护 → 特殊权限设置 → 安装未知应用 → 浏览器 → 允许
  3. 如果被「纯净模式」或「安全守护」拦下，选继续安装，可能要验证一下小米账号。
  4. 装好之后就不用再回这里了。App 会自己检查新版本，下载、校验完直接弹出安装。
